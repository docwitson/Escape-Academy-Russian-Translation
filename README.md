# Русификатор Escape Academy

Автономный установщик русского перевода для Steam-версии Escape Academy.
Русификатор использует внутренний испанский языковой слот и создаёт изменённые
Unity-архивы непосредственно из файлов законно установленной копии игры.
Игровые архивы в репозиторий и релиз не входят.

Это неофициальный фанатский проект, не связанный с Coin Crew Games, iam8bit или
издателями Escape Academy. Репозиторий содержит русский перевод и технические
идентификаторы строк; оригинальный английский сценарий в него не включён.

## Поддерживаемая версия

- Escape Academy `3.0.7.4`
- Steam build ID `20378796`
- Windows x64

После обновления игры установщик должен быть проверен и при необходимости
пересобран для новых контрольных сумм.

## Использование

1. Закройте Escape Academy.
2. Запустите `EscapeAcademyRussianInstaller.exe`.
3. Установщик попробует найти игру во всех библиотеках Steam. При необходимости
   укажите папку `Escape Academy` вручную.
4. Нажмите **Установить** и дождитесь завершения.
5. Запустите игру и выберите **Русский** в настройках языка.

На время установки требуется около 12 ГБ свободного места. После успешной
установки временные сборочные файлы удаляются, а оригиналы остаются в папке
`EscapeAcademyRussian` внутри каталога игры. Кнопка **Удалить русификатор**
восстанавливает оригиналы и удаляет эту папку.

## Сборка EXE

Требуются Python 3.11 и зависимости из `requirements-build.txt`:

```powershell
python -m pip install -r .\requirements-build.txt
.\build.ps1
```

Результат появится в `dist/` вместе с `SHA256SUMS.txt`.

## Диагностические команды

Установщик имеет скрытый консольный режим для автоматического тестирования:

```powershell
.\EscapeAcademyRussianInstaller.exe --self-test
.\EscapeAcademyRussianInstaller.exe --verify --game-dir "D:\SteamLibrary\steamapps\common\Escape Academy"
```

Вывод сохраняется рядом с EXE в `EscapeAcademyRussianInstaller.log`.

## Публикация на GitHub

В репозиторий следует включать исходники, `manifests/`,
`ollama_pipeline/output/`, этот README и сценарий сборки. Каталоги `build/`,
`dist/` и `packaging/` исключены через `.gitignore`. В GitHub Release достаточно
прикрепить:

- `EscapeAcademyRussianInstaller.exe`;
- `SHA256SUMS.txt`;
- краткое описание поддерживаемой версии игры и известных ограничений.

Перед публичной публикацией необходимо выбрать лицензию для кода и отдельно
зафиксировать условия распространения текста перевода.

Сообщения о пропущенном или некорректном тексте лучше оформлять через Issues с
названием комнаты, скриншотом и текстом, который отображается в игре.
